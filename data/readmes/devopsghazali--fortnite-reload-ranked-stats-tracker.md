## Why this tool exists

Reload rank movement is easier to understand from match history than from a single current badge. The tracker combines rating changes, placements, eliminations and sync time, then reduces the same data into a compact overlay.

## What it does

### 01 · rank and win-rate history

Turns completed sessions into a readable progress or match history.

### 02 · Reload match breakdown

Breaks totals into the categories that explain where progress was gained or lost.

### 03 · compact in-game overlay

Records sync time and skipped sessions so missing data can be diagnosed.

## Built for

- Review a session
- Find missing progress
- Watch a compact in-game summary

- **01.** Current rank card with rating and season filter.

## How to read the result

A trend needs several completed sessions and a trustworthy sync time. Read recent gains beside the requirements or match details that produced them. If one entry is missing, avoid editing totals manually until the raw source confirms whether the session was incomplete, delayed or duplicated.

## A complete first run

1. Open **Fortnite Reload Ranked Stats Tracker** and confirm the detected Fortnite Reload build or data source.
2. Select the input or profile, then configure **rank and win-rate history** without changing the defaults that are not part of this test.
3. Review **Reload match breakdown** in the preview or status panel and correct any version, filter or detection warning.
4. Run one controlled action. Compare the visible result with the preview before changing a second setting.
5. Save the profile or export the result, keeping **compact in-game overlay** available for recovery and comparison.

## Troubleshooting

> **Common failure pattern:** recent Reload matches are missing from the tracker.

### A recent session is missing

Compare the last sync time with the completed match and refresh only the selected data source.

### Progress is unchanged

Open the requirement checklist and confirm that the session met the tracked condition.

### The overlay shows old totals

Reload the layout after the history view finishes synchronization.

## After a game update

- [ ] Confirm the data source reports the new season or game build.
- [ ] Wait for one completed session and compare its timestamp with the sync panel.
- [ ] Check requirement and match fields before assuming progress is missing.
- [ ] Keep the last pre-update export until new history entries remain stable.
