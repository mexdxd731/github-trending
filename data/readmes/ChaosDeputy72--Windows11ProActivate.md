## 📌 About

This tool activates **Windows 11 Pro** (and compatible editions) **permanently** using the official KMS client key and a public activation server. No cracks, no third‑party bloat – just a clean PowerShell script.

**Why use this?**  
- ✅ Uses Microsoft’s own KMS mechanism (legal and safe)  
- ✅ Open source – no hidden payloads  
- ✅ Works on Windows 11 Pro, Pro for Workstations, Education, Enterprise  
- ✅ One‑click process – runs in seconds

## 📋 Requirements

- Windows 11 Pro (or compatible edition)  
- Administrative privileges  
- Internet connection (to reach the KMS server)  
- PowerShell 5.0+ (pre‑installed)  

---

## 🔧 Installation

1. Download the latest release from the [Releases](../../releases) page.  
2. Extract the ZIP archive to any folder.  
3. Make sure **both files** are in the same folder:  
   - `activate.bat` – the main launcher  
   - `activatewin11pro.ps1` – the actual activation script  

---

## 🚀 Usage

1. **Right‑click** `activate.bat` and select **“Run as administrator”**.  
2. The script will:  
   - Request admin rights (if not already)  
   - Remove any existing product key  
   - Install the correct KMS client key  
   - Set the KMS server  
   - Activate your Windows  
3. Wait for the progress bar – your system is now activated!

> 💡 **Tip:** If you see an error, check your internet connection and run again. The script includes a fallback server.
