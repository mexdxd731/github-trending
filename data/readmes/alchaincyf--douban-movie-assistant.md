# 豆瓣观影助手

在豆瓣电影/剧集页的侧栏里直接看片：四渠道探测可播放片源、卡片内嵌静音预播、剧集选集、追剧更新提醒。

## 它和别人不一样的地方

- **能找到**：四个渠道并行探测——Internet Archive（授权核验）、Wikimedia Commons（授权标记）、YouTube（片长强闸门）、苹果CMS 资源站（**每条播放链接实测可播才展示**）。资源站搜索词做变体轮询（「第三季」↔「3」↔「龙之家族第三季」↔「痴迷2025」这些收录名差异是踩出来的）。
- **能看**：探测一完成，第一个源**自动在卡片内静音预播**，点画面开声；内置播放器带**音量增强（默认 3×，压缩器防爆音）**——盗版转码源音频电平普遍极低，普通播放器救不了。换源不重建播放器，秒切。
- **能选集**：剧集源展开后有集数按钮组，点集切换，当前集高亮；集数与豆瓣 ±2 校验、首末集实测可播。
- **能追**：点「＋ 追剧」入清单，后台每 30 分钟检查资源站最新集数，有新集弹系统通知（「第 7~7 集已出」），点通知直达豆瓣页；满集自动通知「已完结」。工具栏图标打开追剧面板：进度条 + 已更集数 + 一键取消。
- **能下**：archive/Commons 直链带下载链接；网盘深链（夸克/阿里）折叠在「更多渠道」区，不占首屏。
- **不谎报**：渠道挂了显示「网络不可达」，和「没有源」分开说；跳转搜索类渠道全部标「❔ 未探测」，和「已验证可播」的直链源明确区分——知道什么、不知道什么，视觉上分得清。

## 为什么做这个（2026-08 判断）

豆瓣有最好的「影」数据库，但没有「看」的入口——「在哪儿能看」列的是几家常驻平台，盗版聚合站天天换域名、对自动化探测普遍封闭（JS 守卫/验证页/密码门）。

本插件的定位不是「又一个资源站」，而是**把找片源这件事压缩到豆瓣页面的侧栏里**：合法渠道和第三方渠道分信任层级展示，每一条能播的链接都先验证过再给；验证不了的渠道老实标「未探测」，不假装知道。

## 安装

1. 下载本仓库（Code → Download ZIP，解压）
2. Chrome 打开 `chrome://extensions`，右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选中本文件夹
4. 打开任意 `movie.douban.com/subject/...` 页面

## 架构

```
background.js   四渠道探测与过滤闸门（provider 架构，渠道独立失败互不拖累，15s 封顶）
                追剧清单：chrome.alarms 每 30 分钟检查资源站最新集数，弹系统通知
content.js      豆瓣页元数据提取（含剧集识别/繁体外文名拆分）+ 卡片渲染 + 内嵌播放交互
player.html/js  扩展内置播放页（hls.js + Web Audio 音量增强链）
popup.html/js   追剧面板（进度条、立即检查、取消追剧）
hls.min.js      hls.js 1.6.8 本地化（MV3 CSP 只允许 script-src 'self'，远程 CDN 会被拒）
```

## 已知限制与维护点

- **YouTube clientVersion 会不定期失效**。症状：`estimatedResults` 为 0 或拿不到 videoRenderer。修法：把 `background.js` 里 `YT_CLIENT.clientVersion` 换成当前 YouTube 网页版使用的版本号。
- **资源站 API 域名更换频繁**。探测站源在 `background.js` 的 `MAC_CMS_APIS`（2026-08 实测：非凡/360/量子可用，来源 TVBox 多仓；社区警告 2026 年大部分历史站源已失效）。站死了换域名即可，协议与过滤逻辑不动。
- **资源站下载链接**（`vod_down_url`）当前三家实测域名已死（404），验证自动过滤；换站后若恢复自动生效。
- **跳转搜索类渠道全部「未探测」**：各平台无开放的可用性 API（B站 API 有风控、腾讯搜索页客户端渲染、JustWatch GraphQL 搜索参数逆向未通），上架状态探测暂不可行，以平台搜索结果为准。
- 豆瓣改版可能影响 DOM 选择器，主要是 `h1 span[property="v:itemreviewed"]` 和 `#content .aside` 两处。

## 合规说明

本扩展只提供搜索跳转与直链，不托管、不缓存任何视频内容。资源站为第三方网站，其内容与合法性由网站方负责，请自行甄别；直链均指向原站点，播放行为发生在原站。
