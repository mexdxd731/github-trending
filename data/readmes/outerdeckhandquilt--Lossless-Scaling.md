## 💡 About the Project

This project is a custom fork of the popular Lossless Scaling utility. It aims to provide gamers with a powerful, accessible tool to upscale windowed games to full screen using state-of-the-art spatial scaling algorithms and optical flow frame generation. 

Whether you are trying to squeeze extra frames out of an integrated GPU, playing an older game that doesn't support modern upscaling natively, or looking to utilize **Frame Generation** on unsupported hardware, this tool has you covered.

---

## ✨ Key Features

*   **Universal Frame Generation (LSFG):** Generate high-quality intermediate frames to double or triple your framerate in almost any game, regardless of your GPU brand.
*   **State-of-the-Art Upscaling:** Includes support for modern algorithms like AMD FSR, NVIDIA NIS, xBR, Anime4K, and custom LS1 algorithms.
*   **Hardware Agnostic:** Works seamlessly across NVIDIA, AMD, and Intel graphics cards.
*   **Low Input Latency:** Carefully optimized pipeline to ensure the generated frames do not compromise your gameplay responsiveness.
*   **Plug & Play:** No game modifications or injections required.

## 💻 System Requirements

*   **OS:** Windows 10 / Windows 11 (64-bit) *[Currently Windows-only]*
*   **GPU:** Any DirectX 11 / Vulkan compatible graphics card (Intel, AMD, NVIDIA)

> **Note:** Linux and macOS are not supported in the current build, but cross-platform compatibility is planned for future releases.

## 📥 Installation

You can install this utility in two ways, depending on your preference. Both versions are available on the [Releases page](https://github.com/outerdeckhandquilt/Lossless-Scaling/releases).

### Option A: Standard Installer (`.exe`)
1. Download the latest `LosslessScaling-Installer-vX.X.X.exe` from the Releases tab.
2. Run the executable and follow the on-screen instructions.
3. Launch the app from the Start Menu or Desktop shortcut.

### Option B: Portable Version (`.zip`)
1. Download the `LosslessScaling-Portable-vX.X.X.zip` archive.
2. Extract the contents to a folder of your choice (e.g., `C:\Games\LosslessScaling`).
3. Run `Main.exe` to start the application. No installation required.

---

## 🎮 How to Use

1. Launch the **Lossless Scaling** application.
2. Configure your desired settings (Select Scaling Type, Sharpness, and enable/disable Frame Generation).
3. Launch your game and set its display mode to **Windowed** or **Borderless Windowed** at a resolution lower than your native monitor resolution.
4. Focus on the game window and press the default hotkey (`Ctrl + Alt + S`).
5. Enjoy the boosted performance and upscaled visuals!

*(Tip: You can customize the hotkey and scaling behavior directly in the app settings).*
