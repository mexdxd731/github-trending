# destiny-tool

just a small tool for destiny 2. made it for myself, but maybe someone else finds it useful.

---

## what it does

- reads/writes memory (obviously)
- shows player info, items, positions (ESP-like)
- tests performance (fps, system load)
- grabs system info (cpu, gpu, ram, etc.)
- logs to file or console

---

## how to run

1. grab the latest release from [Releases](https://github.com/yourusername/destiny-tool/releases)
2. unzip it somewhere
3. run `destiny_tool.exe` as **Administrator**
4. tweak `config.ini` if you want

---

## config

example `config.ini`:

## ini
- [Settings]
- VisualsEnabled=true
- PerformanceMode=false
- LogLevel=Info
