## 📌 About

**CS2 Universal Macros** is an all-in-one macro loader for Counter-Strike 2 with a clean GUI interface. Configure recoil compensation, custom keybinds, utility scripts and more — all in one place, no external dependencies needed.

> ⚠️ **Disclaimer:** Use at your own risk. The author is not responsible for any account bans. Recommended for use only on servers where third-party software is permitted.

## 🚀 Getting Started

### Requirements

- Windows 10 / 11
- Counter-Strike 2 (latest version)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/cs2-macros-universal.git

# 2. Navigate to the folder
cd cs2-macros-universal

# 3. Run the loader
Loader.exe
```

That's it — no additional software required. Configure everything directly inside the GUI.

## ⚙️ Configuration

All settings are managed directly in **Loader.exe** — no config files to edit manually.

| Setting | Description |
|---|---|
| **Toggle Key** | Hotkey to enable / disable macros on the fly |
| **Weapon** | Select your active weapon for recoil profile |
| **DPI** | Your mouse DPI (important for recoil accuracy) |
| **Sensitivity** | Your in-game sensitivity |
| **Modules** | Toggle individual features on or off |
