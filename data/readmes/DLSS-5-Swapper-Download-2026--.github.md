## 🧠 Overview

DLSS 5 Swapper brings DLSS 5 installation and configuration into one desktop application, so you don't have to manage every game modification by hand. It can detect games from supported libraries, work with manually added game folders, and provide different installation routes depending on the game and its rendering setup.

For games that already include DLSS, the application offers a native installation route. Compatible titles without native DLSS can use DLSS5-Feeder instead. Additional routes, including OptiScaler and multipass rendering, are available for supported configurations.

The application also keeps track of installation activity and backs up original files, making it easier to undo a change if a particular setup doesn't work as expected. An in-game overlay provides live access to neural rendering controls for supported installation routes.

DLSS 5 Swapper is intended for Windows users who want to experiment with neural rendering across their PC game collection, including selected games running through supported emulators. Results depend on the game, GPU, driver, rendering API, and installation method.

## Additional Information for Windows Users

Close the game before changing its graphics files. Although DLSS 5 Swapper backs up files for supported installation operations, keeping a separate backup of important game data is still a good idea.

Not every game works with every installation route. Existing mods, graphics injectors, rendering APIs, and game updates can affect compatibility. If a modification causes problems, use the restore option before trying another configuration.

The in-game overlay is available only for supported routes and configurations; it is not a universal feature for every installation method. Modifications can also conflict with anti-cheat systems and may cause crashes or account penalties in online games. The application does not bypass anti-cheat protections.

DLSS 5 Swapper is a third-party utility. Its compatibility and results are not guaranteed by NVIDIA or by the developers of individual games.
