## Delta at a Glance

Delta provides a Windows-based Roblox script executor centered on fast Lua injection, an integrated script collection, and a small desktop UI. The layout is intended for people who need to launch scripts, organize multiple entries, and access execution tools without a crowded workspace.

Its workflow brings script loading and discovery together: open the application, add scripts, and browse commonly used Roblox categories through the included hub. Persistent queue support, automatic updates, and multiple interface languages are included for regular Windows usage.

## Common Questions

**Which operating systems can run Delta?**  
Delta is presented as a Windows desktop application and supports Windows 10 and Windows 11.

**Can the application update itself?**  
An auto-update engine is included, allowing newer builds to be processed through the application's update workflow when updates are available.

**What does Delta provide beyond a simple loader?**  
Alongside Lua execution, Delta offers a 500+ script hub, batch operation, a debugger, and SQLite-backed persistent queue storage.

**Could using an executor affect my account?**  
Third-party executors and script-based workflows may involve account risk depending on how they are used and which scripts are loaded. Make informed decisions and observe the applicable platform terms.

**Where does Delta keep queued information?**  
The persistent queue uses SQLite, meaning related application data is stored locally on the computer.
