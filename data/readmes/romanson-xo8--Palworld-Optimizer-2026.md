# 🚀 PalBoost

## Palworld FPS Booster, Performance Optimizer & Gaming Assistant

PalBoost is a lightweight Windows optimization tool designed to improve the overall Palworld gaming experience.

Instead of modifying the game itself, PalBoost optimizes your Windows environment, monitors hardware performance and helps identify common causes of FPS drops, stuttering and unstable frame times.

---

# ✨ Features

## ✅ Smart Performance Optimization

Prepare your PC before launching Palworld.

• Close unnecessary background applications

• Free available system memory

• Enable Windows gaming optimizations

• Reduce background CPU usage

• Optimize power settings

• Improve frame stability
