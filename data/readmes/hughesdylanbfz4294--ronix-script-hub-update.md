## About Ronix

Ronix gives Windows users a direct way to execute Lua scripts through the Roblox client. Its streamlined workflow uses one-click injection to connect with the Roblox process, avoiding manual PID selection, configuration steps, or external keys. The lightweight design is intended to keep resource usage low on systems with modest hardware while maintaining dependable execution.

A built-in Script Hub provides access to more than 500 scripts grouped by game and purpose. Users can browse available entries, preview them, and run them from the same application. Ronix also checks for updates automatically to follow Roblox changes, while its SQLite queue storage preserves script settings and execution history between launches. It can be used for game automation experiments or custom Lua testing on current Windows installations.

## Frequently Asked Questions

**Is Ronix safe to use?**  
Ronix is supplied as-is, and each user is responsible for following Roblox's Terms of Service. The tool does not contain malware, but it should be used at the user's discretion.

**Will Ronix support the newest Roblox release?**  
Its automatic update component is intended to preserve compatibility with current Roblox versions. When problems occur, a patch is generally made available within 24 hours.

**What sets Ronix apart from other free executors?**  
Ronix combines a key-free workflow with a built-in debugger and a persistent queue, capabilities that are commonly associated with paid tools.

**Could using Ronix result in an account ban?**  
Third-party executors always involve risk, and Ronix makes no promise that an account will remain safe. Users who are concerned should consider using alternate accounts.

**Where does Ronix keep my scripts?**  
Imported scripts remain in the local `scripts/custom` directory, while cached Script Hub content is placed in `scripts/hub`. No data is transmitted to external servers.
