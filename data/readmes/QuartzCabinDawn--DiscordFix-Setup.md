## ⚙️ Использование

1. Перейдите на страницу [**Releases**](../../releases) и скачайте последнюю версию **DiscordFix**.
2. Распакуйте архив в папку без кириллицы и специальных символов в пути.
3. При необходимости откройте свойства архива и нажмите **«Разблокировать»**.
4. Запустите нужный файл или используйте `service.bat` для дополнительных настроек.
5. При необходимости протестируйте несколько конфигураций и выберите подходящий вариант.

### 🔧 Проверка конфигураций

Для поиска подходящей конфигурации:

`service.bat` → `Run Tests` → `Standard tests` → `All configs`

Доступность отдельных конфигураций зависит от используемой сети и может отличаться у разных пользователей.

### 🚀 Автозапуск

Для автоматического запуска выбранной конфигурации:

`service.bat` → `Install Service`

После установки выбранная конфигурация будет добавлена в службы Windows и сможет запускаться автоматически.

## 📦 Основные возможности

* Настройка подключения **Discord**
* Набор готовых конфигураций для Windows
* Проверка доступности различных сетевых ресурсов
* Диагностика распространённых проблем подключения
* Настройка **GameFilter TCP**
* Поддержка IPv4 и IPv6
* Управление службами через `service.bat`
* Обновление сетевых списков и конфигурационных файлов
* Ручное тестирование различных вариантов подключения
* Возможность выбора конфигурации в зависимости от используемой сети

## ℹ️ Основные файлы

* **`general.bat`** — ручной запуск выбранной конфигурации.
* **`service.bat`** — управление службами, тестами и дополнительными параметрами.
* **`bin`** — необходимые системные компоненты и исполняемые файлы.
* **`list-general-user.txt`** — пользовательский список доменов.
* **`list-exclude-user.txt`** — список исключений для доменов.
* **`ipset-all.txt`** — список IP-адресов и подсетей.
* **`ipset-exclude-user.txt`** — пользовательские исключения для IP-адресов.

Файлы с суффиксом `-user` предназначены для пользовательских изменений и автоматически создаются при необходимости.

## 🎮 GameFilter

**GameFilter** позволяет отдельно настраивать обработку трафика игр и других приложений, использующих TCP/UDP.

В актуальной версии можно изменять диапазон портов **GameFilter TCP**.

Например, для исключения RTMP можно использовать:

`1024-1934,1936-65535`

После изменения параметров рекомендуется перезапустить используемую конфигурацию.

## 🔍 Диагностика

Если Discord или другой поддерживаемый сервис перестал работать:

1. Запустите `service.bat`.
2. Откройте **`Run Diagnostics`**.
3. Выполните доступные проверки.
4. Проверьте несколько конфигураций через **`Run Tests`**.
5. Сравните результаты разных конфигураций.
6. После изменения параметров перезапустите активную конфигурацию.

> [!NOTE]
>
> Работа конкретной конфигурации зависит от сети, провайдера и текущих условий подключения. Конфигурация, которая работает у одного пользователя, не обязательно будет работать у другого.

## ❓ Частые проблемы

### Discord не подключается

* Проверьте несколько доступных конфигураций.
* Запустите `service.bat` → `Run Diagnostics`.
* При необходимости очистите кэш Discord через доступную функцию диагностики.
* Проверьте подключение к Discord через браузер.
* После смены конфигурации перезапустите Discord.

### YouTube не открывается

* Проверьте несколько конфигураций.
* Убедитесь, что сетевые настройки применились корректно.
* Если проблема появилась после обновления, попробуйте другую конфигурацию.
* Проверьте работу сервиса без активной конфигурации, чтобы определить источник проблемы.

### Игра или приложение перестало работать

Проверьте настройки **GameFilter** и **IPSet Filter**. Изменение этих параметров может повлиять не только на игру, но и на другие сетевые соединения.

### Ни одна конфигурация не работает

Можно выполнить стандартный сброс сетевых компонентов Windows:

```cmd
netsh winsock reset
netsh int ip reset all
netsh winhttp reset proxy
ipconfig /flushdns
```

После выполнения команд перезагрузите компьютер и повторите проверку.

## 🔄 Полное обновление

При переходе на новую версию рекомендуется:

1. Сохранить собственные изменения и пользовательские списки.
2. Удалить старую установленную службу через `service.bat`.
3. Скачать актуальный архив из **Releases**.
4. Распаковать новую версию в отдельную папку.
5. Проверить доступность нужных конфигураций через `Run Tests`.
6. При необходимости снова установить выбранную конфигурацию через `Install Service`.

> [!TIP]
>
> Не рекомендуется заменять отдельные файлы новой версии поверх старой сборки. Для обновления лучше использовать чистую папку и перенести только собственные пользовательские настройки.

## 📝 Добавление собственных ресурсов

При необходимости список поддерживаемых ресурсов можно расширить с помощью пользовательских файлов:

* `list-general-user.txt` — домены и поддомены;
* `list-exclude-user.txt` — исключения для доменов;
* `ipset-all.txt` — IP-адреса и подсети;
* `ipset-exclude-user.txt` — исключения для IP-адресов.

Изменения в пользовательских файлах позволяют добавлять необходимые ресурсы без изменения основных конфигураций проекта.
