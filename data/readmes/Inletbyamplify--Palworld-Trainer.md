## Features

- Pal type, level, and rarity information
- Player health and stamina profiles
- Inventory and carrying settings
- Crafting and building tools
- Movement and exploration controls
- Capture-oriented profile options
- Private-world settings
- Save and load custom profiles

---

## Controls

| Key | Action |
|---|---|
| **Insert** | Open / Close Menu |
| **F1** | Enable Trainer |
| **Delete** | Hide Overlay |

## Requirements

- Windows 10 or Windows 11 (64-bit)
- Supported PC version of **Palworld**
- Current program build
- Administrator permissions only when required by the current release
- Conflicting overlays closed during troubleshooting

---

## Installation

1. Download the latest package using the banner above.
2. Extract the package into a separate folder.
3. Launch **Palworld** and wait until the main menu, character, or world is fully loaded.
4. Run the trainer using the privilege level required by the current release.
5. Press **Insert** to open the menu.
6. Enable only the features you need and configure the preferred hotkeys.
7. After a major game update, check that the installed build is still compatible.
