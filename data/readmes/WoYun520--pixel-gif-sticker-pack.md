# GIF 表情包工作室

给 Codex 一张角色图，让它帮你做一套会动的表情包。

比如你有一个卡通人物或吉祥物，想让它说“收到”“好耶”“抱抱”“我好困”。这套工具会帮你设计表情和动作、加上文字，再把做好的动图打包给你。

做完能拿到一张张单独的 GIF、一个打包下载的文件，以及一段能直接播放的预览视频。GIF 的背景可以是透明的，方便放进聊天里。人物、写实宠物等素材默认直接导出 512 × 512 清晰版；明确要求像素风时使用 320 × 320 像素模式。

## 表情包展厅

已有系列共 **218 张 GIF**，另有 **2 张完整动作修补候选**，待使用者确认。人物高清与连续动作示例为 512 × 512，其余已有示例为 320 × 320；动作小样约 1.12 秒循环，其余约两秒。点击动图可查看原尺寸。新版工具默认导出 512 × 512 清晰版。

**各系列默认收起；点击对应窗口即可展开分类动图。**

[下载整个项目，包含 218 张已有示例和 2 张动作修补候选](https://github.com/WoYun520/pixel-gif-sticker-pack/archive/refs/heads/main.zip)

## 怎么用

你需要在能生成图片、运行脚本的 Codex 中使用它。

**第一步，把下面这句话发给 Codex，安装工具。**

> 帮我安装这个表情包 Skill：https://github.com/WoYun520/pixel-gif-sticker-pack

Skill 可以理解成给 Codex 用的一份做事指南。装好以后，它就知道怎么按这套流程做表情包了。

**第二步，发一张角色图片，再说清楚想做什么。**

比如，把下面这句话和图片一起发给 Codex。

> 使用 $pixel-gif-sticker-pack，拿这张图里的角色做 16 张中文表情包。我要“收到”“好耶”“抱抱”“晚安”这类日常聊天用语，动作活泼一点，帮我打包好，再给我一个能播放的预览。

你也可以直接说“做一套上班用的”“做 30 张安慰人的”或“用我自己的台词”。数量、文字和风格都可以提。

生成时会用到图片生成工具。第一次运行如果缺少做动图的工具，可以让 Codex 帮你检查和安装。

## 画风和动作分开选

画风有三种：**像素风、高清插画风、真人风**。二次元人物、宠物、吉祥物是题材；照片转插画是输入处理方式。真人风保留已认可的人物动作示例，不把未认可的自拍美颜试验当作默认模板。

动作另选：**轻动效**用一张表情图加点头、弹跳、摇摆或符号变化；**完整动作**用连续姿势，让表情、身体及相关头发、服装一起动。高清导出与动作稳定是两件事，可以分别选择。

## 让人物做具体动作

想让人物挥手、点赞、比心，可以直接告诉 Codex 动作。Skill 会改走“连续姿势”流程：先检查少量关键姿势，再补动作阶段；固定镜头和比例，让人物自然活动，逐帧合成 GIF。它和单张图的弹跳、摇摆、挤压是两种制作方式。

连续动作已有独立导出脚本，详见[操作说明](references/keyframes.md)。这种方法适合小动作，可能有跳帧和细节变化；不等同于视频模型生成的连续运动。

## 怎么减少丑帧

完整动作先检查角色的关键姿势，再补过渡。导出后检查每一张实际 GIF 帧、脸部细节、手指和服装，并看正常播放及首尾衔接。有坏帧就修对应片段、重新导出检查，不用模糊或只转手臂来掩盖问题。

工具会生成编号帧、放大检查图和本地播放页；检查记录与具体 GIF 版本绑定，改图后必须重新检查。自动统计只能判断尺寸、透明背景、时长等，不能保证人物一定好看。详细规则见[画面稳定性检查](references/stability.md)。

## 人物或宠物发糊怎么办

写实人物、宠物照片和细腻插画，可以保留原图细节导出清晰版；想要像素风时，继续使用像素化效果。

现在直接调用这个 Skill，就会从原始素材合成 512 × 512 清晰版 GIF，使用平滑缩放和形变，不需要另外修改脚本。预览视频默认不加标题。明确需要像素风时，才切换到像素模式。

你可以对 Codex 说：

> 人物有点糊，请先检查原图与导出过程。保留原图细节，直接合成清晰版 GIF，再给我同尺寸的前后对比。

高清合成已内置到导出脚本。具体规则见 [Skill](SKILL.md) 和[清晰度处理说明](references/clarity.md)。如果原始图片本身已经模糊，仍需换清晰素材；单纯放大不能补回细节。

<details>
<summary>想自己运行脚本？点这里看操作方法</summary>

需要 Python 3 和 Pillow。如果还想生成预览视频，需要安装带有 libx264 的 FFmpeg。

先准备一张透明背景的大图，把各个姿势分别放在大小相同的格子里，再按[清单格式](references/manifest.md)填好每张的文字、位置和动作。

```sh
python3 -m pip install Pillow
python3 scripts/export_pack.py manifest.json build --font /path/to/font.ttf --preview
```

`--font` 后面填你电脑上支持中文的字体文件路径。做好的文件会放在 `build` 文件夹。

默认导出 512 × 512 清晰版。需要像素风时，在上面的命令中加上 `--render-style pixel`。默认动效包括位移、摇摆、挤压和移动小特效。脚本会检查数量、重复图片、动画是否变化、背景是否透明、有没有裁掉内容，以及压缩包能否打开。

</details>
