# 服装资产板生成器

把一张穿搭参考图整理为横向 3:2 服装资产板：左侧展示整套造型，右侧展示可单独截图、复用和混搭的服装拆件。适合准备 AI 视频角色的服装参考，也可为一套原创服装制作资产板。

## 使用

通过 Skills CLI 安装：

```bash
npx skills add nuyoah-ai-works/nuyoah-outfit-asset-generator -g -y
```

安装后提供参考图并说：“把这套衣服提取为整套与拆件资产板。”明确要求生成图片时才调用当前环境可用的生图工具；只要求分析或 Prompt 时输出文字。生成后会交付资产板及实际使用的完整中文 Prompt。

Skill 会区分参考图可见的设计、合理补全与无法确认的细节。背面只有在有辨识价值或你明确要求时才展示；仅有背面参考时，生成的正面是造型提案，不是原衣服的准确还原。

## 范围

本 Skill 不执行角色换装、角色四视图、工厂制版或视频成片。仓库不包含参考照片、示例人物、第三方服装图片或生图服务；使用参考素材及生成结果时，请确认相应权利。图片生成能力取决于安装环境。
