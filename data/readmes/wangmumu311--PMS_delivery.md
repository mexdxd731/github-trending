> 发布日期：2026-09-12 · 版本：v2.0（脱敏交付）
> 主页文件：`app/synapse_pms.html` （单文件即用，零依赖）

## 这是什么

一个**单文件 HTML 应用**——把项目状态、需求、Bug、机器人交流日志、吐槽、自学习闭环看板全部装在 1 个文件里，**双击即可在浏览器打开**，无需任何服务端、无需任何依赖。

它不仅是一个 PM 看板，更是一台**让机器人协作被看见、被反思、被学习**的体检仪：

- 12 个模块覆盖 PM 协作全链路
- 进化闭环（观察 → 对话 → 反思 → 进化）把吐槽 / 日志 / 评审数据自动转化为可执行的规则候选 + 待派工任务

**本包为脱敏演示版**：人员信息已替换为「部门+角色编号」（如 `前端/UI-01`），需求/Bug 数据为虚构示例数据，服务器地址/群 ID/文档 Token 等内部基础设施信息已替换为占位符（`<服务器IP>`、`<群会话ID>` 等）。**同事/新团队拿到后，替换 `data/` 下的 JSON 为自己的数据即可使用。**

## 30 秒上手

```bash
# 1. 双击打开看板（任何现代浏览器即可）
start app\synapse_pms.html

# 2. 或起个本地静态服务（推荐，避免 file:// 限制）
python -m http.server 8000 --directory app
# 然后访问 http://localhost:8000/synapse_pms.html
```

## 接入自己数据（5 步）

1. 打开 `data/bugs_open_conf_v2.json`：把示例 Bug 换成你项目的 Bug（字段见 03 号文档）
2. 打开 `data/story_all_v2.json`：把示例需求换成你项目的需求
3. 编辑 `scripts/rebuild_v5.py` 第 11-18 行 `DEPT_MEMBERS`：换成你的部门人员结构（角色编号模板已备好）
4. 运行 `python scripts/rebuild_v5.py` 重新生成看板
5. 双击 `app/synapse_pms.html` 查看效果

## 核心承诺

- **零依赖**：HTML 单文件，CSS/JS 全内联，离线可看
- **零数据上传**：所有数据静态内嵌，localStorage 仅本机记录派工状态
- **脱敏交付**：无真实人员姓名、无真实需求数据、无内部服务器/群 ID 信息
- **可追溯**：交付包自带干净 git 历史（单 commit，无历史包袱）
