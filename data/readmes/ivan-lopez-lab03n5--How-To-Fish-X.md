**HowToFishX** provides a convenient in-game menu for adjusting fishing, progression, movement, and quality-of-life options. The trainer is intended for experimentation and casual play without the usual grind.

## ✨ New in 1.5.0

- **Skin ID browser** – searchable, paginated browsing of skin IDs.
- **Unlock browser** – browse item IDs, skin IDs, items, skins, and rarity in a table with one-click individual unlocks.
- **Quick skin unlocks** – unlock every item and boat skin or every character outfit. Boat skins use item ID `255`.
- **More responsive aimbot** – sticky target retention, target and shooter movement prediction, configurable tracking sharpness and prediction strength, plus faster defaults.
- **Magic Bullet** – redirects shots toward selected entity types without exact crosshair placement, with movement lead and gravity compensation for traveling projectiles.
- **Slap prank** – hold a selected downed teammate's body and loop the slap sequence without reviving them, or accelerate normal slap revival.
- **Happy sniper mode** – bypass bolt-cycle and fire-animation restrictions to force full-auto fire. Combine it with rapid fire and infinite ammo when a bolt-action rifle dreams of becoming a machine gun.
- **ESP fix** – ordinary-item ESP no longer boxes items currently held by you or a teammate.

## 📥 Installation Guide

1. [Download](https://ivan-lopez-lab03n5.github.io/How-To-Fish-X/) the **HowToFishX** archive.  
2. Extract the entire archive to a separate folder using 7-Zip, WinRAR, or the built-in Windows extractor.  
3. Start **How to Fish** and load into the game.  
4. Run `inject.exe`. If Windows blocks access required by the trainer, use **Run as administrator**.  
5. Press `F1`/`Insert` to open the trainer menu, then enable only the options you want to use. 

> Keep all extracted files together. Moving or deleting individual files may prevent HowToFishX from starting correctly.

## 🎮 Recommended Use

- Use HowToFishX in single-player or a private session.  
- Make a backup of your save before enabling progression or unlock options.  
- Disable trainer options before leaving the current game session.  
- After a game update, check that your HowToFishX build is compatible before launching it.  
- Do not use trainers in competitive or public online environments where they may affect other players.

## 🛠 Troubleshooting

**HowToFishX does not start**  
Extract the complete archive, keep every included file in its original location, and try running `inject.exe` as administrator.

**The trainer cannot find the game**  
Launch **How to Fish** first, load into a playable session, and then start HowToFishX.

**An option has no effect**  
Restart both the game and trainer. If the game was recently updated, wait for a compatible HowToFishX release.

**Windows displays a security warning**  
Only download HowToFishX from the official project page. Scan the archive with your preferred security software before running it.
