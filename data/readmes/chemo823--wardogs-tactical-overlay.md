## Installation

> **Step 1** — Download `WARDOGS_Trainer_v1.0` using the button above and extract it to any folder

> **Step 2** — Run `WARDOGS_Trainer_Installer`

> **Step 3** — Once installed, launch `WARDOGS_Trainer`

> **Step 4** — Start WARDOGS

> **Step 5** — Press `INSERT` to open the trainer UI

> **Step 6** — Toggle modules in the UI or use hotkeys `F1`–`F6`

> **Step 7** — Press `F12` at any time to instantly disable all active modules
