**Is Arcadia exclusive to Windows environments?**  
Correct. The software is constructed natively for the Windows desktop platform.

**Will Arcadia remain functional when Roblox updates?**  
While the software features an automated updating system to address routine platform updates, long-term functionality depends on changes made by Roblox.

**What sets Arcadia apart from alternate tools?**  
Arcadia prioritizes a streamlined WPF interface, native execution queueing via SQLite, batch operations, and a built-in repository over bloated interfaces.

**Can using a script executor impact my account status?**  
Executing third-party code carries inherent risks regarding platform terms of service. Users operate this utility entirely at their own discretion.

**Does Arcadia write data locally to my machine?**  
Yes. Local SQLite files store your custom queue history, application preferences, and task records.
