## 🎯 Overview

**How To Fish Trainer** is a lightweight utility created for the PC version of **How To Fish**.

It provides a convenient in-game menu with configurable options while keeping the interface simple, clean and easy to use.

> ⚡ Built with a focus on simplicity, performance and a smooth user experience.

---

## ✨ Features

| Feature               | Description                                 |
| :-------------------- | :------------------------------------------ |
| 🎮 **Trainer Menu**   | Convenient in-game configuration interface  |
| ⚙️ **Custom Options** | Easily enable or disable available features |
| 🚀 **Lightweight**    | Minimal impact on overall game performance  |

## 🚀 Installation

### 01 — Prepare the Game

Locate your **How To Fish** installation directory.

### 02 — Install BepInEx

Install **BepInEx 5.4.23** into the game's root directory.

Your folder should contain:

```text
How To Fish/
├── BepInEx/
├── doorstop_config.ini
├── winhttp.dll
└── HowToFish.exe
```

### 03 — Run the Installer

Launch:

```text
How To Fish Trainer v2.1 Installer.exe
```

Select your **How To Fish** installation directory and complete the setup.

### 04 — Launch the Game

Start **How To Fish** normally.

The trainer menu should become available once the game has finished loading.
