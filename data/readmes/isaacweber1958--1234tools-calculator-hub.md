## Frequently Asked Questions

### Is downloading a desktop installer required?

No native installation is needed. 1234Tools functions completely inside modern browsers and can be saved as a PWA when supported.

### Are my input parameters uploaded to any server?

No. Every utility operates on client-side script execution, meaning your data remains strictly local and is never transmitted externally.

### Can I run calculations offline?

Utilities that have been launched previously while online can remain available for offline use depending on browser storage policies.

### What is the best way to locate a specific conversion tool?

Navigate through the main category directories to narrow down tools by field, then click the exact module you need.

### Do I need Node.js or a build script to compile the project?

No. The codebase consists of pure HTML, CSS, and JS, eliminating any need for compilation or bundling.

### What troubleshooting steps should I take if a tool refuses to open?

Verify that JavaScript execution is allowed in your browser settings and perform a page refresh. If testing local repository files directly from disk, serve the project through a lightweight HTTP server to bypass browser security policies.

### Where can I check for updates?

The live deployment link always hosts the newest version of the platform. Code improvements and repository updates are regularly pushed to the main repository.
