# 🚌 SmartBus – Smart Bus Tracking and Management System

## 📌 Project Overview

SmartBus is a web-based Bus Tracking and Management System designed to simplify public transportation management.

The application allows users to view bus routes, bus stops, bus timings, and bus tracking information. The system also provides an admin module to manage buses, routes, stops, timings, and tracking details efficiently.

---

## 🚀 Features

### 👤 User Features

- 🚌 View available buses
- 🛣️ View bus routes
- 📍 View bus stops
- ⏰ Check bus timings
- 🗺️ View route maps
- 📡 Track bus locations

### 👨‍💼 Admin Features

- ➕ Add buses
- ✏️ Update bus details
- 🗑️ Delete bus details
- 🛣️ Manage bus routes
- 📍 Manage bus stops
- ⏰ Manage bus timings
- 📡 Update bus locations
